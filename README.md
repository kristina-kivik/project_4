### Тестирование многошаговой формы выбора тарифного плана



В рамках учебного проекта выполнен анализ требований, тестовой документации и реализации многошаговой формы выбора тарифного плана.



#### Выполненные работы:



* Декомпозиция требований к вёрстке: дополнена декомпозиция интерфейса для разделов «Форма Шаг 4» и «Окно подтверждения тарифного плана».



* Декомпозиция требований к логике: проработаны сценарии выбора тарифного плана с помесячным обслуживанием, а также выбора дополнительных опций для годового и месячного тарифов.



* Тест-дизайн: заполнены пропущенные разделы таблицы принятия решений (№ 4–13, 20–29, 36–44) для определения комбинаций условий и ожидаемого поведения системы.



* Разработка чек-листов на вёрстку: добавлены недостающие проверки № 15, 30–33 для оценки корректности отображения элементов интерфейса.



* Разработка чек-листов на логику: дополнены проверки № 55–63, 81–84, 91–93 для тестирования функциональности формы, выбора тарифов и дополнительных опций.



* Ручное тестирование: выполнены подготовленные проверки на тестируемой реализации, результаты зафиксированы в чек-листах с соответствующими статусами.



* Документирование дефектов: при обнаружении ошибок составлены баг-репорты со ссылками на выявленные проблемы.
